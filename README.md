# mpei.fish

Неофициальный студенческий архив решённых работ МЭИ: контрольные, типовые расчёты, лабы, чертежи и билеты по семестрам.

Бесплатная схема: статический сайт на GitHub Pages, файлы на публичном Яндекс Диске.
Своего сервера нет, персональные данные не собираются, трекеров и сторонних CDN нет.

## Как устроено

| Файл | Что это |
|---|---|
| `index.html`, `style.css`, `main.js` | Сайт |
| `rules.html` | Правила, страница для правообладателей, конфиденциальность |
| `config.js` | Ссылка на Яндекс Диск, форму для присылки работ и почту для жалоб |
| `data/catalog.json` | Список предметов по семестрам |
| `data/s/*.json` | Файлы каждого предмета |
| `data/search.json` | Индекс для поиска |
| `tools/build_catalog.py` | Собирает `data/` из публичной папки Яндекс Диска |
| `fonts/`, `vendor/` | Шрифты (OFL) и GSAP, лежат локально |

Файл скачивается так: браузер запрашивает у публичного API Яндекс Диска
(`cloud-api.yandex.net/v1/disk/public/resources/download`) прямую ссылку и сразу её открывает.

## Обновить каталог

Добавил файлы на Яндекс Диск, после этого:

```bash
python tools/build_catalog.py
```

Скрипт обходит папку и заново собирает `data/`. Из каталога исключаются папка «Программы», `.exe`, `.djvu`,
мусорные файлы (`.ithmb`, `.bak`, `Thumbs.db`). Правила исключения и названия предметов — в начале скрипта.

## Запустить локально

```bash
python -m http.server 8810
```

и открыть http://localhost:8810.

## До публикации

- В `config.js` заполнить `contactEmail` (почта для правообладателей) и, когда будет форма, `uploadUrl`.
- Убрать из публичной папки Яндекс Диска то, что не должно быть доступно: программы, учебники, файлы с чужими ФИО.
